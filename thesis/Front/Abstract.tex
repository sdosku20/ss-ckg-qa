Clinical knowledge graphs store medical entities, such as diagnoses, drugs, and lab results, together with the relations between them, in a form that is precise and can be audited fact by fact. This makes them attractive as a backend for question answering, but querying them becomes difficult once a large language model (LLM) is placed in front of the graph as a natural-language interface. Passing an entire graph to an LLM as context does not scale well, since even a moderately sized clinical graph produces far more text than a model can process in one prompt. What is needed instead is a retrieval step that first picks out only the part of the graph relevant to a given question. This thesis implements and evaluates one such approach, the Prize-Collecting Steiner Tree (PCST) based subgraph selection strategy introduced by G-Retriever, on a real clinical knowledge graph built under the Swiss Personalized Health Network (SPHN) schema and scoped to the Swiss Transplant Cohort Study (STCS) at University Hospital Basel.

The central question is whether PCST-based selection, which keeps the retrieved subgraph connected while controlling its size, finds more accurate and more compact answers than SnapQuery, the assistant that clinicians and researchers at the STCS Data Center already use today to ask questions about the cohort in plain language. Given a question, SnapQuery has a language model write and run a single database query and returns the matching rows directly, without exposing any retrieved subgraph of its own. Two simpler internal baselines, similarity-only top-$k$ retrieval and breadth-first expansion, are included alongside PCST-based selection to show how much of any improvement comes from enforcing connectivity itself rather than from the underlying similarity scores. All three approaches are compared using answer-node recall at a given subgraph size, first over the full set of real questions clinicians have already asked the system, and then on a smaller set of about 50 questions whose correct answers have been manually confirmed. As an optional extension, the thesis also asks whether adding intent and schema signals to the PCST prize function can improve this trade-off further.
